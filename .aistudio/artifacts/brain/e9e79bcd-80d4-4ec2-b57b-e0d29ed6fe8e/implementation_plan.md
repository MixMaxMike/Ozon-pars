# План нормализации прямых ссылок на фото Ozon в Google Таблицах

Исправление проблемы с неработающими ссылками на фотографии: нормализация всех URL-адресов фото до стабильного открываемого формата `https://c.cdn.ozon.ru/s3/multimedia-1/[ID].jpg` с сохранением привычного вывода прямых кликабельных ссылок в ячейках Google Таблицы.

---

## Подтверждённые требования пользователя

> [!IMPORTANT]
> - **Формат ссылки**: Оставляем прямые текстовые кликабельные URL-ссылки в столбцах «Фото 1» ... «Фото 6» и «Все фото списком» (без формулы `=IMAGE()`).
> - **Устранение ошибок открытия**: Автоматическая замена закрытых внутренних адресов `ir.ozone.ru/s3/.../wc1200/` на открытые публичные адреса CDN Ozon (`c.cdn.ozon.ru/s3/multimedia-1/...jpg`), которые мгновенно открывают полноразмерное изображение при клике из Google Таблицы или браузера без ошибок 403.

---

## 1. Причина ошибки и способ её решения

### Причина 403 при клике по ссылкам Ozon:
Ссылки формата `https://ir.ozone.ru/s3/multimedia-1/wc1200/6082918231.jpg` содержат служебный путь `/wc1200/` и хост `ir.ozone.ru`. Сервер Ozon блокирует прямые переходы по таким ссылкам вне сайта ozon.ru (проверяет заголовок `Referer`). При клике из Google Таблицы браузер переходит с `docs.google.com`, и Ozon возвращает страницу ошибки 403 / 404.

### Преобразование URL:
Преобразуем все ссылки товаров к публичному формату CDN Ozon, не требующему заголовок `Referer`:
- ❌ Было: `https://ir.ozone.ru/s3/multimedia-1/wc1200/6082918231.jpg`
- ✅ Станет: `https://c.cdn.ozon.ru/s3/multimedia-1/6082918231.jpg`

При клике по новой ссылке любое устройство и любой браузер моментально отображают оригинальную фотографию товара в полном разрешении.

## 2. Изменения в коде

1. **`src/data/titanGsData.ts`**:
   - Функция нормализации `normalizeOzonPhotoUrl(url: string)`:
     ```typescript
     export function normalizeOzonPhotoUrl(url: string): string {
       if (!url) return '';
       // Извлекаем ID мультимедиа (например, 6082918231.jpg)
       const match = url.match(/(?:multimedia-\d+\/)?(?:wc\d+\/)?([a-zA-Z0-9_\-]+\.(?:jpg|jpeg|png|webp))/i);
       if (match && match[1]) {
         return `https://c.cdn.ozon.ru/s3/multimedia-1/${match[1]}`;
       }
       return url.replace('ir.ozone.ru', 'c.cdn.ozon.ru').replace('/wc1200/', '/');
     }
     ```
   - Прогон всех 152 фото всех 62 товаров Титан-GS через данную нормализацию.

2. **`src/services/googleSheetsService.ts`**:
   - В выгрузке TSV для копирования (Ctrl+V) и в автономном Google Apps Script каждая ячейка фото отдает нормализованную прямую кликабельную ссылку `https://c.cdn.ozon.ru/s3/multimedia-1/...jpg`.

3. **`src/components/GoogleSheetsModal.tsx` & Таблице товаров (`ProductTable.tsx`)**:
   - Обновление ссылок на фото во всех модальных окнах, карточках и таблице приложения.
